# 🧮 Web Calculator

A simple, responsive, and user-friendly calculator web application built using **HTML5, CSS3, and JavaScript**.

This project was developed as part of my **Web Development Internship at CodeOrbit Tech** to gain practical experience in front-end web development, JavaScript functions, event handling, responsive design, and input validation.

---

## 📌 Project Overview

The Web Calculator is a browser-based calculator that performs common mathematical operations.

The application provides a clean and simple user interface where users can enter numbers and perform calculations directly in their web browser.

The project is completely front-end based and does not require any backend server or database.

---

## 🎯 Objectives

The main objectives of this project are:

- To understand the basic structure of a web application.
- To practice HTML for creating the calculator interface.
- To use CSS for designing a clean and responsive layout.
- To use JavaScript for implementing calculator functionality.
- To understand JavaScript functions and DOM manipulation.
- To handle user input and invalid calculations.
- To implement division-by-zero error handling.
- To create a responsive application that works on different screen sizes.
- To practice organizing and uploading a project to GitHub.

---

## ✨ Features

### 🔢 Basic Arithmetic Operations

The calculator supports:

- Addition `+`
- Subtraction `−`
- Multiplication `×`
- Division `÷`

### 📊 Additional Features

- Percentage `%`
- Decimal numbers
- Clear All (`AC`)
- Delete Last Character (`DEL`)
- Equals (`=`)
- Responsive design
- Clean calculator interface
- Button hover effects
- Invalid input handling
- Division-by-zero handling
